How Trivia Royale 20 Works

  • 20-Player Lobby: Every match has 20 total combatants. Every player/bot starts with 3 lives (❤️❤️❤️).
  • 6-Second Matchup & Power-Up Preview: Before every question, a 6-second VS screen reveals your opponent, both players' remaining lives, and lets you activate Power-Ups for the upcoming duel.
  • 1v1 Pairings: Each round, surviving players face off with a 20-second timer. (If an odd number remain, one player receives a Bye).
  • Winning a Duel: Fastest correct answer wins. The loser loses 1 life (or 2 lives if Double Jeopardy is active).
  • Answer Streaks (🔥): Real players who answer 4+ questions in a row right and before their opponent earn a flame badge showing their live streak, which carries across games.
  • Ties & Double Misses: If both answer wrong (or time out), both lose 1 life. If both answer right in the exact same time, neither loses a life.
  • XP, Levels & Skin Unlocks: Everyone starts at Level 0 (0 XP). Earn +1 XP per correct answer plus placement bonuses: Top 10 (+5 XP), Top 7 (+10 XP), Top 5 (+20 XP), Top 3 (+40 XP), 2nd (+60 XP), 1st (+80 XP), or Undefeated 1st without losing a heart (+150 XP). Every 1,000 XP advances you +1 Level (resetting XP to 0) and automatically unlocks new Prestige Skins!
  • Juggernaut Power-Up (🦾): Costs 3,000 🪙 and can only be activated on the Round 1 VS screen before Question 1 to start the match with 5 ❤️ instead of 3 ❤️. Each game, there is a 3% chance a random bot spawns with Juggernaut.
  • Quick Match & Private Rooms: Click Quick Match to automatically join an open 60-second public lobby (or create one if none are open) to play with random players online, or use a 5-character Room Code for private matches. Bots never spawn as Very Hard, and if the host is eliminated early, the match keeps running so all remaining players can finish!
